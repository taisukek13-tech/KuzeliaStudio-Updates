# Kuzelia Studio

配信録画から切り抜き・縦ショートを作るWindows 64ビット版アプリです。場面探し、字幕、見出し、構図、音声調整をPC内で行います。

最新版は **v0.20.19**（2026年11月23日公開）です。

[最新版の配布ページ](https://github.com/taisukek13-tech/KuzeliaStudio-Updates/releases/latest)

## インストール済みの方

「アプリを更新」→「最新版を確認・取得」→「更新して再起動」で更新してください。素材・完成動画・作品設定・通常の設定を保持します。通常の更新にZIPやセットアップの手動導入は不要です。

処理速度を優先するには、ホームの設定で「このPCの処理速度を優先する」を押してから自動作成を開きます。GPU優先・通常のCPU使用・対応NVIDIA書き出しをまとめて設定します。ほかの作業と同時に使う場合はCPU使用量を減らせます。

## 初めて使う方・アプリを修復する方

最新版の配布ページから、`KuzeliaStudio_Setup`で始まるEXEを選びます。起動中のアプリを終了してから実行してください。セットアップは新規導入・修復用です。修復には同じ版か新しい版を使います。

ホームの「設定・AIの準備」で状態を確認します。基本字幕AIは同梱。自動の場面選びには初回に追加AI約8.9GBが必要です。今回、大型AIモデルは追加・交換していないため、準備済みモデルの再取得は不要です。

## 最初の1本

1. 「録画を選んでAIで作る」または「配信アーカイブからAIで作る」を選ぶ。
2. 声の音声トラック、保存先、本数を確認して作成を始める。独立したマイク音声があれば優先して選ぶ。
3. 完成動画を再生し、冒頭と結末、字幕の言葉・時刻、タイトル、構図、音を確認する。
4. 必要なら「字幕・構図を調整」で直し、MP4を書き出す。

MP4は投稿・再生用、作品設定は編集を続けるためのファイルです。作品設定に元動画は含まれないため、元動画も保持してください。

## 0.20.19の改善

- 右下に人物を含む一体型と、下部を人物に使う全幅構図を両方扱い、指定した構図・元の切り抜き範囲・表示方法を保持します。
- 確認した元領域の形に合わせて構図の基準を選び、候補同士を同じ基準で比較します。自動表示では人物の縦横比を保ち、明示した表示方法は維持します。
- 自動タイトルを左右の安全な余白に収め、余白設定を変えたときにも配置へ反映します。手動の見出し位置は保持します。
- 確認済みの字幕を、認識結果の再整形で書き換えないようにしました。未確認の自動字幕に対する従来の整形は引き継ぎます。
- プレビューと書き出しの準備を画面処理から分離しました。準備が重なった場合のフォントコピー競合と、中止時の後片付けも見直しています。

画質・fps・音声認識AI・大型AIの配布モデルと、既存の小型学習方針は維持しています。今回、新しい学習重みは採用していません。人物範囲や字幕の確認待ちは、見た目が整っただけで確認済みにはしません。

## これまでの改善と主な機能

- 見出し、字幕、人物の大きさと配置を見直しました。参考映像から測った構図と小型の学習モデルを使い、主映像と右下の人物が一体に見える配置を選びます。指定した元領域や手動の構図は保持します。
- 見出し候補を比較し、実際の文字の形を使って大きさと空間を調整します。字幕は中央を揃え、画面端の安全な余白を守ります。
- 字幕の登場演出を追加学習しました。読む量や発話の休止に合わせて、静止か小さな拡大から戻る動きを選びます。短い・密度が高い・連続する字幕では読みやすさを優先し、手動の演出は保持します。
- 会話・リアクション・解説に合わせて書体を選び、見出しと発話の違いを読み取りやすくします。確認待ちの字幕は見た目の調整だけで確認済みにしません。
- 条件が一致する解析結果やAI処理の再利用、画面を固めにくくする処理、GPU失敗時のCPU復帰など、これまでの速度対策を引き継ぎます。

大型AIや音声認識AI本体を今回再学習したものではありません。外部サイトからの新しい参考動画の取得や、人による完成動画の品質評価は行っていません。素材によって字幕・構図の修正は必要です。

複数本の作成、制作の再開、完成一覧、冒頭比較、30/60fps、対応GPUでの字幕認識、フォント追加、AI保存先の移動・再利用データ整理も利用できます。完成ファイルの解像度・fps・長さ・全編デコード・音量や、字幕と見出しの配置を検査し、確認点を記録します。

「アプリ判定」は編集の確認点の点数です。人気・再生数の予測や、人が確認した字幕正解率ではありません。投稿前に完成動画を再生してください。混合音声からの自動話者判別・声の分離は行いません。

フォントの利用条件・作者・必要なクレジットは、アプリの設定で確認できます。

## 困ったとき

- AIの準備に失敗：設定で保存先・空き容量を確認し、「保存したAIを確認」。途中の取得は再開できます。
- 制作を中止：完成済み動画は保持します。「前回のAI制作を再開」、完成一覧、保存済み作品を確認してください。
- 自動字幕が出ない：「字幕・構図を調整」で確認待ちの案を見直し、音を聞いて修正して「確認済み」にします。「確認待ちの自動字幕も表示」で案を表示できます。
- タイトルや字幕の配置で止まる：保存した作品を開き、見出し表示・入力したタイトル・字幕の位置や分割を修正してください。
- 空き容量が少ない：設定から管理下の古い再利用データを整理できます。素材・完成動画・作品・AIモデルは対象外です。
- 更新できない：アプリの複数起動や使用中ファイルを確認して再試行してください。起動できない場合は、同じ版か新しい版のセットアップで修復します。

詳しい手順は「使い方・困ったとき」、記録は「診断・不具合報告」から開けます。報告には版、再現する操作、エラー全文を添えてください。素材や個人情報の公開は不要です。
