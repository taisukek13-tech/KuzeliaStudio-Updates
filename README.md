# Kuzelia Studio

配信録画から切り抜き・縦ショートを作るWindows 64ビット版アプリです。場面探し、字幕、見出し、構図、音声調整をPC内で行います。

[最新版の配布ページ](https://github.com/taisukek13-tech/KuzeliaStudio-Updates/releases/latest)

## インストール済みの方

「アプリを更新」→「最新版を確認・取得」→「更新して再起動」で更新してください。素材・完成動画・作品設定・通常の設定を保持します。

0.18.6で処理速度を優先するには、ホームの設定で「このPCの処理速度を優先する」を押し、自動作成を開きます。GPU優先・通常のCPU使用・対応NVIDIA書き出しをまとめて設定します。ほかの作業と同時に使う場合はCPU使用量を減らせます。

## 初めて使う方・アプリを修復する方

最新版の配布ページから、`KuzeliaStudio_Setup`で始まるEXEを選びます。起動中のアプリを終了してから実行してください。セットアップは新規導入・修復用です。修復には同じ版か新しい版を使います。

ホームの「設定・AIの準備」で状態を確認します。基本字幕AIは同梱。自動の場面選びには初回に追加AI約8.9GBが必要です。今回の改善でAIモデルを追加・交換していないため、準備済みモデルの再取得は不要です。字幕GPU用の実行部品約22.7MBはアプリ更新に含みます。

## 最初の1本

1. 「録画を選んでAIで作る」または「配信アーカイブからAIで作る」を選ぶ。
2. 声の音声トラック、保存先、本数を確認して作成を始める。独立したマイク音声があれば優先して選ぶ。
3. 完成動画を再生し、冒頭と結末、字幕の言葉・時刻、タイトル、構図、音を確認する。
4. 必要なら「字幕・構図を調整」で直し、MP4を書き出す。

MP4は投稿・再生用、作品設定は編集を続けるためのファイルです。作品設定に元動画は含まれないため、元動画も保持してください。

## 0.18.6の改善

- 字幕認識にも対応GPUを利用。GPU配置を確認できない・処理に失敗した場合は、終了後に同じ音声をCPUで認識します。
- CPUの使用数をPCに合わせて調整し、独立した字幕用音声を最大3区間まで並列で準備します。制作中の同じAIファイルの重複読み込みも減らします。
- 書き出す実際の作品から字幕とタイトルの配置を再検査。自動ショートのタイトルが空・非表示の場合や、字幕・見出しのはみ出し・重なりがある場合は、作品と確認点を保存して修正を案内します。
- 完成ファイルの正方画素・解像度・fps・長さ・全編デコード・音量を検査。詳細編集後も新しい内容に対して記録を作ります。
- 未確定の字幕、独立した認識照合の未完了、タイトル案は確認待ちとして残します。

これまでの自動字幕の「笑、」「（笑）」等の非発話表記の抑制、動画内タイトル、複数本の作成、制作の再開、完成一覧、冒頭比較、30/60fps、フォント追加、AI移動・再利用データ整理も利用できます。手入力と音を聞いて確認済みにした表記は保持します。

「アプリ判定」は編集の確認点の点数です。人気・再生数の予測や、人が確認した字幕正解率ではありません。字幕の誤りや構図提案の誤りは残るため、投稿前に再生して確認してください。混合音声からの自動話者判別・声の分離は行いません。

フォントの利用条件・作者・必要なクレジットは、アプリの設定で確認できます。

## 困ったとき

- AIの準備に失敗：設定で保存先・空き容量を確認し、「保存したAIを確認」。途中の取得は再開できます。
- 制作を中止：完成済み動画は保持します。「前回のAI制作を再開」、完成一覧、保存済み作品を確認してください。
- 自動字幕が出ない：「字幕・構図を調整」で確認待ちの案を見直し、音を聞いて修正して「確認済み」にします。「確認待ちの自動字幕も表示」で案を表示できます。
- タイトルや字幕の配置で止まる：保存した作品を開き、見出し表示・入力したタイトル・字幕の位置や分割を修正してください。
- 空き容量が少ない：設定から管理下の古い再利用データを整理できます。素材・完成動画・作品・AIモデルは対象外です。
- 更新できない：アプリの複数起動や使用中ファイルを確認して再試行してください。起動できない場合は、同じ版か新しい版のセットアップで修復します。

詳しい手順は「使い方・困ったとき」、記録は「診断・不具合報告」から開けます。報告には版、再現する操作、エラー全文を添えてください。素材や個人情報の公開は不要です。

## 検証範囲

0.18.6は実FFmpegを含む896項目、実音声認識37項目、GPU切替の模擬21項目、梱包16項目が通過。[Windows検証](https://github.com/taisukek13-tech/KuzeliaStudio-Updates/actions/runs/42174654082)で27画面、実際の日本語認識とGPU失敗時のCPU復帰、1080p30/60fpsの4出力、旧版からの署名付き818ファイル更新・再起動、新規導入・修復・削除と利用者データ保持を確認しました。

同じ10区間の音声準備は旧0.18.5と交互に各4回測り、中央値1.465→0.848秒、約42%短縮。全区間のPCM音声はバイト一致。同じ実配信の3場面も、字幕・タイトル・音声を含むMP4が旧0.18.5とバイト一致しました。3本には投稿前の確認点が残ります。

速度比較はLinux共用CPUでの音声準備工程です。動画全体・利用者PC・実GPUの短縮率ではありません。Windowsは標準VM・100%表示倍率。実GPUの速度・字幕精度、利用者PC、全DPI、全ジャンルの採用率、人手の字幕正解率は未測定です。更新ヘルパー試験は画面の更新ボタンからのネットワーク取得とは別です。

アプリ内更新のRSA署名とWindowsのコード署名は別です。Windowsコード署名用証明書は未設定です。公開物に開発用ソース、秘密鍵、利用者の録画、内部評価データを含めません。
