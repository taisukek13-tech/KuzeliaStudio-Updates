# Kuzelia Studio 更新配信

Windowsアプリ Kuzelia Studio の署名付き更新ファイルを配信します。

[最新版と更新パッチ](https://github.com/taisukek13-tech/KuzeliaStudio-Updates/releases/latest)

0.13.0／0.13.1／0.14.0／0.14.1／0.14.2のインストール版は、AddInAppUpdateのZIPを展開し、EXEを一度実行してください。アンインストールは不要です。
更新後は起動時に最新版を取得し、準備完了を通知します。更新するときは「更新して再起動」を押します。

公開しているのは実行用パッケージと更新情報です。試験版のためWindows実機でのGUI・終了／再起動は未検証です。
